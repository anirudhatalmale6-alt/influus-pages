# Influüs — service pages

Preview of the two pages describing what Influüs sells:

- **press-service.html** — press releases, guest posts and brand mentions,
  with the three formats explained and the catalogue in figures.
- **matchmaking.html** — brands ↔ creators: the three programs, the process,
  and the five audience tiers.

Every figure on the press page is read from the live influus.com catalogue
(159 placements, 126 publications, $95–$1,500, median $350, 52 Do-Follow),
not typed by hand.

Each page also exists as a single self-contained block that can be pasted
straight into an Elementor HTML widget — all CSS is prefixed `.ifs` so
nothing leaks into the Ohio theme.
